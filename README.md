# 👻 Phasma‑Phoney 3D

A real-time ghost investigation game built using Babylon.js and WebGL.  
Use equipment, track sanity, explore a haunted environment, and survive encounters with 25 uniquely-behaving ghost types.

---

## 🎮 Features

- 25 unique ghost profiles (including shapeshifters, fire-sensitive types, sanity-based hunters)
- Real-time exploration of a haunted house (GLB model)
- Interactive tools: EMF, Spirit Box, Camera, Flashlight, Thermometer, Crucifix, and more
- Notebook & ghost guessing logic
- Audio/visual ghost events and ambient SFX
- Full hunt logic: smudging, fire interaction, LOS evasion, hiding
- Babylon.js with modular scripts and fully embedded assets
